01. Executive Summary

SHIVAM CREATES is a premium, cinematic digital creative agency platform engineered to position itself as the go-to creative ecosystem for fast-growing brands across India and globally. This PRD defines the complete product strategy, technical architecture, design system, and development roadmap required to build and launch a world-class agency platform that competes with top-tier creative studios globally.

The Core Mission
To transform the way brands discover, engage with, and retain a premium digital agency — delivering Awwwards-caliber design, full-stack engineering, motion graphics, branding, and performance marketing from a single unified ecosystem.

The Opportunity
India's digital economy is growing at 20%+ YoY. SMBs, D2C brands, and startups are actively seeking premium creative partners who can deliver agency-grade output without enterprise pricing. SHIVAM CREATES targets this gap — premium aesthetics at accessible starting prices — creating a powerful brand moat.

02. Product Vision

SHIVAM CREATES is NOT just a portfolio website. It is a scalable digital agency ecosystem — a platform that generates leads, builds trust, closes clients, manages projects, and grows into a full-scale SaaS CRM for creative agencies.

Short-Term Vision (0–6 Months)
	•	Launch MVP: Landing Page, Portfolio, Services, About, Contact, Blog
	•	Appointment Booking + Smart Lead Form integrated with Supabase
	•	Fully dynamic Admin CMS to manage all content
	•	Mobile-first, cinematic UI that outclasses 99% of freelancer portfolios
	•	SEO-optimized to rank for local + niche service keywords

Mid-Term Vision (6–18 Months)
	•	Client Dashboard: project tracking, file sharing, revision history
	•	Invoice & Payment system (Razorpay integrated)
	•	Team management for scaling to a multi-person agency
	•	AI proposal generator to convert leads faster
	•	White-label mode for partner agencies

Long-Term Vision (18+ Months)
	•	Full SaaS CRM for creative agencies — white-labeled
	•	AI website builder widget embedded in client dashboard
	•	Subscription retainer plans for recurring revenue
	•	Marketplace for digital assets created by Shivam Creates
	•	Internship & mentorship program platform

11. Authentication & Security Architecture

11.1 Authentication Flow
	•	Visitor hits /admin — Next.js middleware checks for active Supabase session
	•	If no session → redirect to /admin/login
	•	Admin logs in via Email/Password OR Google OAuth
	•	Supabase issues JWT — stored in httpOnly cookie (SSR safe)
	•	Middleware validates JWT on every admin route request
	•	Role check: only users with role='admin' in users table can access admin routes
	•	Session refresh handled automatically by Supabase client

12.2 Performance-Conscious Animation Rules
	•	All Framer Motion animations use GPU-accelerated properties: transform, opacity
	•	Never animate width, height, top, left (causes layout thrashing)
	•	Use will-change: transform sparingly (only on critical animated elements)
	•	Respect prefers-reduced-motion: all animations disabled for users with this OS setting
	•	Heavy background animations (particles) use requestAnimationFrame + canvas, not DOM manipulation
	•	Lazy load Framer Motion for non-hero sections to reduce initial bundle
